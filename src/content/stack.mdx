The software and tools I'm currently using to build, ship, and stay organized. This is a living list — I'll keep it updated as my setup evolves.

### The stack

- [**Vercel**](https://vercel.com) — Where this site lives. Push to Git and it ships: instant preview deploys, a global edge network, and zero config.
- [**Claude Code**](https://www.anthropic.com/claude-code) — Anthropic's agentic coding tool in the terminal. My go-to pair programmer for building and shipping.
- [**Codex**](https://openai.com/codex) — OpenAI's coding agent. I run it alongside Claude Code to get a second set of hands on a problem.
- [**Conductor**](https://conductor.build) — A Mac app for running multiple coding agents in parallel, each in its own isolated workspace.
- [**Notion**](https://notion.so) — My second brain. Notes, docs, plans, and project tracking all live here.
- [**Bubble**](https://bubble.io) — The no-code platform I build full apps on. I'm a [certified developer](https://bubble.io/certificate/xkky8ygt4g83) and Bubble Ambassador.
